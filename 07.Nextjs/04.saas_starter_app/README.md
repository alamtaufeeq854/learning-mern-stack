# SaaS Starter App

A full-stack SaaS Todo application built with **Next.js, Clerk, Prisma, and PostgreSQL**.

## Features

- 🔐 Clerk Authentication
- ✅ Create & manage Todos
- 🔍 Search & pagination
- ⭐ Subscription-based Todo limits
- 🔄 Clerk Webhook user synchronization
- 🗄️ Prisma + Neon PostgreSQL
- 🚀 Vercel deployment

## Tech Stack

- Next.js
- TypeScript
- Clerk
- Prisma
- PostgreSQL (Neon)
- Tailwind CSS
